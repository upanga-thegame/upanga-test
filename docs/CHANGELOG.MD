# Upanga Changelog

## 2026-07-28

### A clearer road ahead

The core systems are now around 90% complete. Work is focused on the backend systems that make story changes easier to manage, along with the remaining cinematic scenes and story beats.

## 2026-05-20

### The game reaches a device

The first working Android build was exported and tested on a mobile device. UI scaling was added so dialogue and menus remain readable across different screen sizes. A standalone build tool now handles headless builds and device installation when a phone is connected.

## 2026-05-18

### Time in battle

Battle time tracking now records how long a mission takes and keeps a best time for each battle. Dialogue frames are also being rebuilt from layered UI panels to improve readability and reduce the number of loaded sprite assets.

## 2026-05-17

### The first field notes

Chapter 1 is planned around five regions, with each region containing two maps and a mini-boss encounter. The first region is complete, a day/night cycle now shapes the travel map, and the wider world of Bomende is taking form.
